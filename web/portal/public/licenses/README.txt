HEIC conversion uses heic-to 1.6.7 (LGPL-3.0), including libheif and its decoders.
Source, license and build instructions: https://github.com/hoppergee/heic-to/tree/v1.6.7
Unmodified package source: https://registry.npmjs.org/heic-to/-/heic-to-1.6.7.tgz
The library is loaded as a separate JavaScript chunk only when native decoding fails.
